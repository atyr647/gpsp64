# Added from profiling the animated title screen with native/bench.sh:
#   BENCH_INPUT=none ./native/bench.sh anim
#   tools/suggest_targets.py bench-results/anim.pages
# Only the highest-value Thumb pages are included: the long tail of small
# pages roughly doubles generated code size for ~1% each, which is a poor
# trade for N64 RAM.  Percentages are share of interpreted instructions.
